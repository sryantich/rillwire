# Rillwire — working identity

Pronunciation: “rill-wire.” A rill is a small stream; the name connects lightweight flow with a communications channel. Tagline: **Conversation, in its element.** Name is provisional; initial search was not trademark clearance.

The original mark uses three interwoven rounded paths, suggesting streams and continuity. It is provided in `site/mark.svg`. It does not use Discord's Clyde, wordmark or branded colors. The site hero expands the same geometry into a large ribbon.

Typography: system UI/Segoe UI; no external font request. Voice: calm, precise, playful sparingly. Prefer “native research preview” until access and release gates pass. Avoid unverified speed multiples, memory-reduction percentages and implied Discord endorsement.

Motion: brief, event-driven transitions only; respect reduced-motion preferences. Avoid persistent animated backgrounds in the desktop app. The static web concept is separate from the native renderer and is not evidence of its performance or visual parity.
