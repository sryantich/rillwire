# Primary source register

Accessed 2026-09-27. These are source-backed findings; recommendations and budgets elsewhere are project decisions. Service docs and dependency APIs can change. No third-party blog is used as technical authority.

## S01
[Discord patch notes, September 8, 2026](https://discord.com/blog/discord-patch-notes-september-8-2026) — current desktop Electron and reported aggregate performance changes.

## S02
[Discord OAuth2 reference](https://docs.discord.com/developers/topics/oauth2) — scopes, local RPC and partner restrictions.

## S03
[Discord automated user-account policy](https://support.discord.com/hc/en-us/articles/115002192352-Automated-User-Accounts-Self-Bots) — self-bot restriction and account enforcement risk.

## S04
[Social SDK communication features](https://docs.discord.com/developers/discord-social-sdk/core-concepts/communication-features) — game integration, approval, messaging/voice requirements.

## S05
[Discord Terms of Service](https://discord.com/terms) — effective September 29, 2025; software restrictions and stated exceptions. This is policy text, not a legal determination about this project.

## S06
[Discord Gateway](https://docs.discord.com/developers/events/gateway) — WebSocket, versioning, heartbeat, sequence/resume and compression.

## S07
[Discord rate limits](https://docs.discord.com/developers/topics/rate-limits) — bucket/global scope and Retry-After semantics.

## S08
[Discord voice connections](https://docs.discord.com/developers/topics/voice-connections) — voice Gateway v8, UDP, transport encryption, DAVE and enforcement date.

## S09
[Official libdave repository](https://github.com/discord/libdave) and [DAVE protocol whitepaper](https://daveprotocol.com/) — reference implementation and protocol. Verify licenses at the revision adopted.

## S10
[egui repository](https://github.com/emilk/egui) and [eframe 0.36.2 API](https://docs.rs/eframe/0.36.2/eframe/) — native rendering, platform support, App API and AccessKit feature.

## S11
[Iced repository](https://github.com/iced-rs/iced) and [releases](https://github.com/iced-rs/iced/releases) — alternative Rust toolkit; 0.14 release researched.

## S12
[Gio](https://gioui.org/) — native Go UI architecture and platforms.

## S13

## S14

## S15
[Vesktop](https://github.com/Vencord/Vesktop) — Electron-based alternative reference.

## S16

## S18

## S19
[Windows Performance Recorder](https://learn.microsoft.com/en-us/windows-hardware/test/wpt/windows-performance-recorder) and [WPR command reference](https://learn.microsoft.com/en-us/windows-hardware/test/wpt/wpr-command-line-options) — ETW/WPA workflow and commands.
